# Having Trouble Installing the Game?

Because our game is brand new, some devices or operating systems may temporarily display security warnings before enough players have installed it. This is normal for many newly released indie games and does **NOT** mean the game is malicious.

## Android Installation Guide

If Android displays any of the following warnings, it is usually because the game was downloaded outside of the Google Play Store or is a newly released APK:

* *“Blocked for your protection”*
* *“Install unknown apps”*
* *“This file may be harmful”*
* *“For your security, your phone is not allowed to install unknown apps”*

### Method 1 — During Installation

1. Tap the downloaded game file (`.apk`).
2. When the Android warning screen appears, tap **Settings** or **Install anyway**.
3. Toggle on **Allow from this source**.
4. Return to the installer and tap **Install**.

### Method 2 — If Installation is Blocked Completely

1. Open your device **Settings**.
2. Go to **Security** → **Apps** → **Privacy** *(varies by device)*.
3. Find and tap **Install Unknown Apps**.
4. Select the browser or file manager app you used to download the game.
5. Toggle on **Allow from this source**.
6. Re-open the downloaded game file and tap **Install**.

> 💡 **Important Note:** After installation, you can safely disable “Allow from this source” again if you want to restore your original security settings.

## Windows PC Installation Guide

If Windows displays any of the following warnings, it is simply because the game is newly released and Windows has not yet built reputation data for it:

* *“Windows protected your PC”*
* *“Unknown Publisher”*
* *“Microsoft Defender SmartScreen prevented an unrecognized app from starting”*

### Step-by-Step Installation

1. Double-click the installer or game executable (`.exe`).
2. On the blue Windows warning screen, click **More info**.
3. Verify the game name, then click **Run anyway**.

### If Windows Defender Deletes or Quarantines the File

1. Open **Windows Security**.
2. Go to **Virus & threat protection** → **Protection history**.
3. Find the blocked game file in the list.
4. Select **Allow on device** or **Restore**.
5. Launch the game again.

> ⚠️ **Important Note:** You do **NOT** need to completely disable your antivirus software or Windows Defender to play the game.

## Mac Installation Guide

If macOS displays any of the following warnings, it is because the game is newly released outside of the Mac App Store:

* *“Apple could not verify this app”*
* *“App is from an unidentified developer”*
* *“Cannot be opened because Apple cannot check it for malicious software”*

### Method 1 — Open Anyway

1. Try opening the game normally. When the warning appears, click **Done**.
2. Open **System Settings** and navigate to **Privacy & Security**.
3. Scroll down until you see the blocked game notification.
4. Click **Open Anyway** and confirm by clicking **Open**.

### Method 2 — Right-Click Open Method

1. Locate the game app in **Finder**.
2. Right-click (or `Control` + click) the app and select **Open**.
3. On the macOS warning dialog, click **Open**.
*(This permanently approves the app on your Mac).*
